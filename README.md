# Parallel K-Means Clustering

---

## Overview

This project implements the **K-Means Clustering Algorithm** in Java using both sequential and parallel approaches with the **Fork/Join Framework**.

The project focuses on improving clustering performance through parallel processing while maintaining clustering quality.

---

## Objectives

- Implement the K-Means clustering algorithm
- Apply parallel programming using Fork/Join
- Compare sequential and parallel execution
- Evaluate clustering quality using SSE
- Visualize clusters using Java Swing

---

## Key Features

- 🔹 Sequential K-Means Clustering
- 🔹 Parallel K-Means using Fork/Join
- 🔹 Random Centroid Initialization
- 🔹 Euclidean Distance Calculation
- 🔹 Iterative Centroid Updates
- 🔹 Convergence Detection
- 🔹 Runtime & Speedup Comparison
- 🔹 SSE (Sum of Squared Errors) Evaluation

---

## Technologies Used

- Java 25
- Apache NetBeans 31
- Apache Ant
- Java Fork/Join Framework
- Java Swing

---

## Performance Evaluation

The project compares both implementations using:

- **Runtime:** Time required to complete clustering
- **Speedup:** Sequential runtime divided by parallel runtime
- **SSE:** Measures clustering quality based on distances between points and centroids

## How to Run the Project

1. Clone the repository:
   ```bash
   git clone https://github.com/khaleddosama/Parallel-KMeans-Clustering.git
   ```
2. Open the project in Apache NetBeans.
3. Build the project using Apache Ant.
4. Run the application.
5. Select the clustering parameters and execution mode.
6. View the clustering results and performance comparison.
